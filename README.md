# Планировщик занятости кабинетов кафедры

Выпускная квалификационная работа по теме:  
«Планировщик занятости кабинетов кафедр, написанный на 1С».

## Описание проекта

Система предназначена для бронирования и мониторинга занятости кабинетов кафедры.  
Серверная часть реализована на платформе «1С:Предприятие 8.3», мобильное приложение — на Flutter.

Система позволяет пользователям просматривать состояние кабинетов, создавать и отменять бронирования, отслеживать ближайшие занятия, а администратору — управлять пользователями, блокировать кабинеты и формировать расписание.

## Основные возможности

- авторизация пользователей;
- просмотр списка кабинетов;
- просмотр карточки кабинета;
- создание бронирований;
- отмена бронирований;
- проверка пересечений по времени;
- административная блокировка кабинетов;
- формирование расписания;
- отчеты по бронированиям и загрузке кабинетов;
- мобильный доступ через Flutter-приложение.

## Структура репозитория

1c/            — выгрузки конфигурации 1С, листинги и скриншоты
flutter/       — мобильное приложение Flutter
docs/          — дополнительные материалы, схемы и изображения
README.md      — описание проекта

## Используемые технологии

- 1С:Предприятие 8.3;
- Flutter;
- Dart;
- HTTP-сервис 1С;
- JSON.

## Запуск проекта

1. Развернуть информационную базу 1С из конфигурации `.cf`.
2. Опубликовать HTTP-сервис `RoomAPI`.
3. Перекинуть apk. файл на телефон для установки мобильного приложения
4. На телефоне выпонить установку и открть приложение
5. В мобильном приложении указать адрес опубликованного HTTP-сервиса 1С.
6. Можно работать как в 1С, так и на мобильном устройстве
